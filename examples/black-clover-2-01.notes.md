## Таблички
- **Царство Пик** (1761): японский проявляется 1761→~1785 → `fade_frames [1761, 1786]`. План идёт с наплыва,
  кадры 1752–1760 чистые → `pre` для медианы (снег). Глифы до y=995, линия со стрелками 998–1001 → низ зоны 997.
  Мелкая фактура города → `encode {block 2, maxK 64, tau 3}`.
- **Замок Клевера** (4200): текст с первого кадра плана, чистых кадров нет → `inpaint` + `affine` без `attached`.
  Светлые зубцы стены детектор принимал за буквы → `detect: thr 30, minc 220, absw 235` (буквы ≥240, камень
  ≤200 — замер `TS probe`). Под буквами зубцы размыты заливкой (прикрыто ореолом текста).
- **Начало битвы** (8117): `ref 8116`, тень иероглифов со сдвигом (12,12) → `detect.shadow`;
  `detect.frames [8117,8119]` (дальше по глифам бегут трещины); `exclude` для ECC — «ページ・171» и нижний текст.

## Карточки
- **Фуэголеон**: box из analyze захватывал волосы (двигаются у левого завитка) → box x0 = 1040.
- **Джек**: рядом с титулом пуговица плаща двигается до ~22719 → `plate [22723,22781]`, `zone_limit` зоны
  титула x < 722. Рука проходит по карточке только в кадре 22691 (в 22692–22694 она уже выше маски).
- **Трое рыцарей**: камера наклоняется вниз на 891–899 px за 122 кадра с замедлением. Один элемент на троих
  с общим ROI давал ложный боковой сдвиг (2D-корреляция по плащам и пуговицам: −165…+126 px, на деле 0) →
  три элемента, у каждого ROI — тело над своей карточкой, `motion: {path, axis: "y", clip: "mask"}`,
  `tol 0.25, rel 0.1`, `mask_dil 16`, `geom_frames [22940,22969]` (фон уже стоит).
- **Ральф**: `path` показывал края прямоугольного клипа → `linear` (остаток 0.15 px), клип по маске.
- **Юно**: очень светлое розовое небо — геометрия автоматически не находится → `geom_only`:
  `cx 414, line 861, underline 927, L 190, R 640, fl_in 252, fr_in 586`, зоны [[150,795,682,868],[258,868,580,922]],
  `glow_box [180,772,650,990]`; `clip: mask`, `mask_dil 14`. Слабый «ящик» над титулом (ореол крупного японского
  титула выходил за маску) убран расширением заплатки на ореол (`halo`, по умолчанию с октября 2026).
