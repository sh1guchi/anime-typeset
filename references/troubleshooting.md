# Симптом → что крутить

| Видно на check | Причина | Что сделать |
|---|---|---|
| Остались края японских букв / ореол | маска мала | `detect.dil` / `mask_dil` больше; `thr` меньше; проверь `zone` захватывает всё |
| Заплатка «съела» элемент оформления (линию, завиток, стрелку) | зона/маска залезла | сузить `zone` / `zone_limit`; для карточек — элемент должен быть вне `zones` |
| Заплатка темнее/светлее фона, пятно | фон под текстом не как вокруг: свечение, градиент, засветка во времени | static: проверь `plate` (медиана по кадрам без движения); plate/ref: `ring` ближе к зоне, больше `color_keys`; card moving: `"glow": "fit"` |
| Вокруг заплатки `ref` тёмные «призраки» контуров японских букв | мягкая тень/ореол текста шире маски | `halo: 10` (заплатка забирает ореол настоящими пикселями из чистых кадров); или больше `detect.dil` |
| Застывшие снежинки / искры в заплатке `ref` | медиана `pre` не убрала всё | больше кадров в `pre`; `clean.fill: "lama"` (LaMa только там, где чистые кадры расходятся) — и проверь `TS lama-ab` |
| Шрифт почти не виден (тонкий «карандаш») | штрих тоньше пары пикселей при реальном кегле | `TS fonts --match --with` помечает `! thin` (`--min-px`); жирнее начертание / другой шрифт |
| Русские буквы стоят «в разрядку» (Ц а р с т в о) | японский шрифт с моноширинной кириллицей | другой шрифт; `--specimen` такие не показывает, `--with` помечает `! full-width` |
| Текст под углом / в перспективе стоит плоско | обычный `pos` | `"quad"` (`TS place ... --box` для поворота, `--quad` по углам вывески для перспективы) |
| Перспектива `\frx\fry` в плеере не такая, как в чеке | камера libass — в пикселях видео плеера | `"quad"`-текст (рисунок) вместо тегов |
| Заплатка мутная на текстуре (кирпич, ткань) | `inpaint` гладкий | `clean.mode: ref` если есть чистые кадры; иначе `clean.fill: "lama"` (дорисовка фактуры, technique.md «LaMa»); без LaMa — меньше `dil` и `feather` больше |
| Видны квадратики/ступеньки | грубое квантование | `encode.block` 2–3, `maxK` больше, `tau` меньше |
| Видна сетка из тёмных линий | перекрытие полупрозрачных блоков | не трогать `ext` у полупрозрачных (в коде уже встык); проверь, что PlayRes в конфиге = скрипта |
| На движении заплатка «плывёт» относительно фона | трек неверный | другой `motion.roi` (фон без персонажей, с текстурой); `linear` → `path`; для зума — `rows`/`exclude` |
| На проезде дёргается на стыках отрезков | `path` слишком грубо | `motion.tol` 0.25, `rel` 0.1 (больше строк) |
| Заплатка закрывает пуговицу/руку/волосы, которые двигаются | маска на движущемся объекте | `zone_limit`, `plate` по кадрам, где объект стоит; иначе `protect` |
| Русский текст выше/ниже японского | базовая линия | `name_base_off`/`title_base_off` в пресете или `base` в тексте; меряй `ruler` |
| Текст не помещается между завитками | длинное имя | `maxw` (сжатие `\fscx`), `name_em` меньше; титул ужимается сам по `title_maxw` |
| Цвет заплатки чуть другой во всём кадре | нет/не та `YCbCr Matrix` | в .ass и в сабах должна быть `TV.709` (merge/assemble ставят сами) |
| `geometry detection failed` / `geom` не нашёл карточку | светлый фон, нестандартная карточка | `geom_only` + ручные `geom` (с `fl_in`/`fr_in`), `zones`, `glow_box` (меряй `ruler`; см. config.md) |
| Файл огромный | много отрезков/цветов | `block` 4, `maxK` 28–40, `rect_clip` (path), `tau` 5 |
| Шрифт «не тот» в рендере | шрифт не установлен или имя семьи другое | `TS fonts --grep`; поставить шрифт / положить в `font_dirs`; имя в стиле = family name |
| Установленный `.otf` в рендере стал Arial (Arno Pro, Garamond Premier Pro) | libass на Windows (DirectWrite) находит некоторые CFF-шрифты только по PostScript-имени | имя в стиле — то, что печатает `TS fonts --match --with` (`ArnoPro-Regular10pt`, проверено через libass: `fontlib.libass_name`) |
| Гладкие прямоугольники на текстуре (сетка экрана, кирпич) | `inpaint` не умеет текстуру | если есть кадры без текста — `clean.mode: ref`; иначе минимальная маска (`dil` меньше) и смириться, или `text` без маски; (идея на будущее: заливка периодической текстурой) |
| Тёмный текст не стирается вообще | маска ищет светлые глифы | `detect.polarity: "dark"`, подбери `thr`/`maxc` |
| Цветная кайма (красно-синяя аберрация) осталась вокруг стёртых букв | кайма не тёмная и не светлая | `maxc` выше (до 200), `thr` ниже, `dil` 8–12 |
| Надпись на экране/доске «уплывает» от объекта при движении камеры | текст считается оверлеем | `attached: true` + `motion: affine` (+ `clean.ref`) |
| Картинка анализа/рендера сплюснута | нестандартное соотношение сторон | инструмент берёт его из видео (ширина 1920, высота по аспекту); PlayRes должен иметь тот же аспект |
| Склейка не найдена, надпись начинается не со склейки | плавное затемнение/вспышки | `analyze` снапит только ошибки ≤4 кадров; границу ищи `TS grid` и ставь `frames` руками |
| Заплатка залила светлые детали фона (зубцы стены, снег на крышах) тёмным | детектор принял их за буквы | `TS probe --box <глифы> --bg <фон>`: `minc`/`absw` между фоном и буквами (напр. камень ≤200, буквы ≥240 → `minc 220, absw 235`), `thr` выше |
| Обрывки низа букв у линии со стрелками | низ зоны на линии или ниже | `TS probe` показывает строки глифов и строки линии → низ `zone` = верх линии − 1 |
| Трек правдоподобный, но заплатка уезжает вбок (или вверх) | 2D-корреляция зацепилась за ложный пик по одной оси (ряды пуговиц, складки) | `TS track` по нескольким ROI: если по оси, где камера стоит, треки расходятся — `motion.axis` по другой оси; сборка сама предупреждает (`! track along x ...`) |
| «Ящик» вокруг заплатки движущейся карточки: тёмная рамка вокруг светлого прямоугольника | ореол крупного японского текста выходит за маску | `halo` (по умолчанию 0.015; в логе `halo: patch grows by ...`); не растёт — `halo_reach` больше; на очень светлом небе ещё `"glow": "fit"` |
| Светлые «провалы» в ореоле между завитком и коротким русским именем (статичная карточка) | японское свечение убрано вместе с текстом | `glow_band: true` (в пресете BC включено) |
| Резкий край заплатки виден сам по себе (не ореол) | цвет фона чуть не совпал | `motion.feather: 2` (кольца наружу), `seam` не выключай |
| Рука/персонаж проходит перед статичной карточкой, а заплатка его закрывает | маска поверх движущегося объекта | `occluders: {"thr": 35, "min_px": 400}` у элемента — покадровый `\iclip` |
| На табличке в рамке видны контуры стёртых букв / пятна мозаики, фуригана оставила точки | маска глифов на градиенте/обводке | зона `{"box": ..., "fill": "auto"}` — внутренность таблички заменяется целиком полосами; в логе `zone [...]: N plate(s) ...` |
| `fill: auto` пишет `no plate (rejected: not flat ...)` | у таблички текстура / 2D-свет | `fill_tol` больше, если в превью не видно; иначе обычная маска |
| `fill: auto` пишет `not enclosed` / `edge is not plate colour` | нет замкнутой рамки (табличка сливается с фоном) или рядом клетка с тем же цветом | обычная маска глифов; `fill_step` 2, если заливка протекает через тонкую рамку |
| Серые «призраки» иероглифов туши на бумаге / доске / свитке (тёмные пятна по форме букв) | гармоническая заливка берёт края маски на размытом крае штриха | `inside: {"poly"/"ellipse": ..., "fill": true}` по всей плоскости бумаги/доски — гладкая поверхность по фону внутри фигуры |
| Заплатка на движении (`attached` + `affine`) чуть другого цвета, сероватая | подгонка цвета по кольцу вокруг: там рука, тень рукава, линии | `colfit` теперь робастный (выбросы отбрасываются); если всё равно — `ring.outer` уже, на чистом фоне; начни элемент после прохода тени |
| Заплатка овала/рамки «съедает» внутренний край кольца ступеньками | фигура `inside` касается рамки, патч рисуется блоками и раздут на 3 px | `ring_gap` больше (5–8), `band` больше, если рамка от руки заходит внутрь эллипса глубже |
