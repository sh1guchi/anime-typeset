# episode.json — формат

Все координаты — в пикселях 1920×1080 («пиксели анализа»), независимо от разрешения видео и PlayRes скрипта.
Кадры — номера кадров видео (0 = первый), диапазоны включительные.

## Верхний уровень

| поле | что |
|---|---|
| `video` | путь к видео |
| `source_signs` | файл надписей переводчика (оттуда PlayRes и стили, которые `merge` удалит из сабов) |
| `preset` | имя файла из `presets/` без `.json` или путь к своему пресету |
| `playres` | `[x, y]` PlayRes результата (по умолчанию — как в `source_signs`); должен совпадать с сабами при merge |
| `out` | куда писать надписи (относительно папки episode.json или абсолютный) |
| `subs` | диалоговые сабы для `merge` |
| `preview` | путь превью mp4 |
| `font_dirs` | папки со шрифтами релиза (участвуют в поиске шрифтов для замеров) |
| `merge_drop_styles` | явный список стилей, строки которых `merge` удаляет из сабов (обычно не нужен) |
| `compact` | `false` — не ужимать строки заплаток при сохранении (по умолчанию ужимаются без изменения картинки, см. technique.md) |
| `source_styles`, `source_events` | стили и все строки файла переводчика — пишет `analyze`; конфиг работает, даже когда исходный файл перезаписан результатом |
| `items` | список элементов (ниже) |

Общие поля элемента: `id` (латиница), `name` (заголовок блока в .ass), `type`, `frames: [f0, f1]`,
`skip: true` — временно исключить. От `analyze`: `source_frames` (тайминг переводчика), `source_lines`
(его строки этой надписи — именно их `merge` уберёт из сабов), `source_boxes` (рамки этих строк, px анализа).

## Текст (`text`, `texts`) — общий формат

```json
{"text": "Царство Пик", "preset": "sign", "em": 66, "x": 960, "base": 983, "fade_frames": [1759, 1783]}
```
- `{"source": true}` — вместо своего текста взять строки переводчика (`source_lines` элемента) как есть:
  `retime` (по умолчанию true — на кадры элемента), `layer` (прибавка к их слоям, 20), `tags` (теги в начало),
  `only: [i, ...]` — только эти строки по номеру, `drop_drawings: true` — без рисунков CR (`\p1`-плашек: их
  заменяет наша маска, текст остаётся). Стили переводчика попадают в результат; совпадающие по имени с
  пресетом получают суффикс ` CR`. Строкам добавляется `\q` с `WrapStyle` исходного файла (наш скрипт —
  `WrapStyle: 2`, иначе длинные строки CR, рассчитанные на автоперенос, уходят за край кадра).
- `text` — строка, `\\N` = перенос (в JSON обратный слэш удваивается).
- слои: `layers: [{style, layer, tags, offset:[dx,dy]}]` или `preset: "sign"|"title"|...` (берёт `layers` из
  одноимённого раздела пресета). Нижние слои — тень/свечение, последний — сам текст (по нему меряется шрифт).
- размер: `em` — кегль (высота em-квадрата) в пикселях анализа → `\fs` по метрикам шрифта;
  или `fs` — сырой `\fs` в единицах PlayRes; иначе размер из стиля.
- позиция: `x` + `base` — центр по x и **базовая линия** (так совпадает с японским текстом), ставит `\an2`;
  `align: "left"|"right"` — тогда `x` — левый/правый конец строки (`\an1`/`\an3`; списки, записки);
  или `pos: [x, y]` с выравниванием стиля (`an` — явный `\anN`).
  `move_by: [dx, dy]` — строка равномерно едет на столько px за время элемента (`\move` вместо `\pos`):
  текст без маски на медленной панораме.
- `maxw` + `fit: "squeeze"|"shrink"` — ужать по ширине (`\fscx`) или уменьшить кегль, если шире.
- `spacing` — межбуквенный интервал, px анализа. `fade: [in_ms, out_ms]` или `fade_frames: [a, b]`
  (проявление за время от кадра a до кадра b). `tags` — любые дополнительные теги.

## type: card — именные карточки с орнаментом

```json
{"id": "fuego", "type": "card", "frames": [22583, 22628],
 "motion": "static",
 "plate": [22583, 22628],
 "cards": [{"box": [1040, 590, 1900, 790], "title": "Капитан Ордена «Багряных львов»", "name": "Фуэголеон Вермилион"}]}
```
- `cards[]`: `box` — область поиска карточки (с запасом); `title` (необязательно), `name`.
  Геометрия (подчёркивание, завитки, верхняя линия, японский текст) находится автоматически; проверить:
  `TS geom`. Если не находится (очень светлый фон) — `geom_only: true` + `geom` + `zones` + `glow_box`:
  - `geom: {cx, line, underline, L, R, fl_in, fr_in}` — центр, y верхней линии и подчёркивания, x концов
    подчёркивания, x внутренних краёв завитков. Без `fl_in`/`fr_in` имя не ужимается по ширине между завитками;
  - `zones` обязательны: прямоугольник титула (от верха глифов до линии + 7) и имени (между линией и
    подчёркиванием, по x — между завитками); точки на концах линии — внутри зоны титула, иначе их ореол
    обрежется прямой кромкой;
  - `glow_box` — рамка всех белых элементов карточки с ореолом (+20–30 px), по ней подгоняется свечение.
  `zone_limit`: обрезать зоны стирания (один бокс или список по зонам, `null` = не трогать) — когда рядом
  с текстом движется что-то, что нельзя закрывать. `protect` — области, которые не считать элементами карточки.
  `title_em`, `title_maxw`, `name_em` — переопределить размеры пресета (`title_maxw` — макс. ширина титула).
- `source_text: true` (уровень элемента) — карточки чистим своими масками, а текст оставляем как у переводчика.
- `motion`: `"static"` | `{"mode": "linear", "roi": [x, y, w, h]}` | `{"mode": "path", "roi": [...], "tol": 0.35, "rel": 0.15}`.
  `roi` — участок фона рядом с карточкой (без персонажей), по которому меряется сдвиг. `linear` — равномерная
  панорама (одна прямая), `path` — неравномерная/долгая (кусочно-линейная, много отрезков, клип прямоугольником).
  У `path` клип — прямоугольник маски **в каждой зоне** (титул и имя отдельно, завитки не попадают);
  внутри прямоугольника всё держится на модели свечения и оценке фона — на текстуре (пальто, пуговицы) или
  очень светлом небе края прямоугольника видны. Тогда `"clip": "mask"` — клип по форме маски, как у `linear`
  (файл больше), и меньше `mask_dil` (14–16), чтобы край прятался под ореолом русского текста.
  `"axis": "y"` (или `"x"`) — трек только по одной оси по профилю строк ROI: для наклона камеры над
  периодичными деталями (ряды пуговиц), где 2D-корреляция цепляется за ложный боковой пик. Сборка сама
  предупреждает, если 2D-трек видит заметный сдвиг по оси, которого не видит профиль этой оси. Проверить ROI
  без сборки: `TS track -c episode.json --frames a:b --roi x,y,w,h [--roi ...]` (таблица сдвигов по ROI,
  масштабам и методам + подсказка `axis`). `total shift` в логе сборки должен совпадать с тем, что видно на `grid`.
  `scale` — масштаб кадров для трека (`path` 0.5, `linear` 1.0).
  `"feather": 2, "feather_w": 4` — растушёвка края заплатки наружу (2 кольца по 4 px с убывающей
  непрозрачностью; элементы карточки не задевает). Нужна редко: «ящик» вокруг заплатки обычно не от резкого
  края, а от ореола японского текста (см. `halo`). Файл растёт примерно вдвое.
  Несколько карточек на одном проезде (фигуры на разной глубине) — отдельные элементы со своим `roi` у каждой.
- Свечение карточки (тёмный ореол вокруг белых элементов; модель `I = B·(1−a) + C·a`):
  - `glow`: `"fit"` — подогнать модель по самой карточке (МНК по ореолу на гладко залитом фоне), или словарь
    `{sig, w, C}`, или не задавать — модель пресета (`card.glow_fit: true` в пресете = всегда `fit`). Подгонка
    печатает `rms` с моделью и без; если модель ничего не объясняет — откат на пресет;
  - `halo` (порог, 0.015; `0` — выключить), `halo_reach` (40 px) — у движущихся карточек заплатка расширяется на
    ореол японских глифов (то, что реально видно в кадрах сверх свечения оставшихся элементов, ближе к
    японскому тексту, чем к элементам карточки); внутри заплатки рисуется только свечение элементов, которые
    остаются. Без этого ореол крупного японского текста вокруг маски даёт тёмную рамку вокруг светлого
    «ящика»;
  - `seam` (true) — граничные значения свечения внутри заплатки берутся из того, что видно в кадрах прямо
    за её краем (модель — лишь подгонка), чтобы не было ступеньки на краю;
  - `glow_band` (static, пресет `card.glow_band`) — у статичной карточки свечение вычитается из фона, фон
    заливается, а ореол строится заново гладким вдоль всей строки: короче японского русское имя не оставляет
    светлых «провалов» между завитком и текстом.
- `occluders` (static): `{"thr": 35, "min_px": 400, "dil": 6}` — когда что-то проходит перед статичной
  карточкой (рука, персонаж), на кадрах, где пиксели под заплаткой отличаются от чистого фона больше `thr`,
  заплатка и текст вырезаются `\iclip` по этому объекту.
- `plate: [a, b]` (static) — кадры для медианы чистого фона (по умолчанию весь план; сократи, если в начале
  плана что-то двигается). `geom_frames` — кадры для поиска геометрии. `mask_dil` (28) — насколько раздувать
  маску японского текста (захват свечения). `encode: {block, maxK, feather, tau}`.

## type: plate — надпись на фоне (таблички, титры, название серии)

```json
{"id": "pik", "type": "plate", "frames": [1759, 1841], "zone": [700, 893, 1220, 997],
 "detect": {"frames": [1790, 1799], "thr": 20, "minc": 120, "win": 61, "absw": 200, "dil": 16, "close": [25, 5]},
 "clean": {"mode": "ref", "ref": 1758, "pre": [1753, 1757]},
 "motion": {"mode": "affine", "rows": [620, 1075], "exclude": [[630, 850, 1290, 1015]], "denoise": true},
 "ring": {"outer": [0, 600, 1920, 1080], "inner_pad": [60, 40]},
 "segments": [[1759, 1799], [1800, 1841]], "color_keys": [],
 "encode": {"block": 3, "maxK": 56, "tau": 4.0},
 "text": {...}}
```
- `zone` — где стирать (маска не выйдет за неё), или `zones: [[...], ...]` — несколько зон в одном элементе
  (доска с подписями, экран с полями). Элементы оформления рядом (стрелки, рамки) оставь вне зон.
  Зона может быть словарём `{"box": [x0,y0,x1,y1], <ключи detect>}` — своё обнаружение для этой зоны
  (одна табличка заливается целиком, рядом — обычная маска глифов).
- `inside` — маска глифов остаётся только внутри фигуры: `{"ellipse": [cx, cy, a, b, angle]}` (угол по часовой,
  в градусах) или `{"poly": [[x, y], ...]}`, можно списком. Для наклонного текста в нарисованной рамке (овал на
  карте): прямоугольная зона цепляет саму рамку, а тёмная/светлая рамка ловится как глиф и стирается.
  `"fill": true` в фигуре — **вся фигура** заменяется гладкой квадратичной поверхностью цвета, подогнанной по её
  же пикселям вне глифов (лог: `inside fill: surface over N px, residual R levels`). Для туши на бумаге/доске
  (свиток, табличка, овал на карте): гармоническая заливка по краю маски тянет серый от размытых краёв штрихов и
  оставляет «призраки» иероглифов, а поверхность их не видит. Рамка вокруг (кольцо овала, край доски) защищена:
  тёмные штрихи, лежащие в основном снаружи фигуры, в полосе `band` (12 px) у её края не заливаются, а заливка
  отступает от них на `ring_gap` (5 px). Иероглиф, касающийся рамки, у точки касания остаётся (несколько px).
  Текстуру (волокна бумаги, древесину) поверхность не повторяет — делай фигуру по всей плоскости (весь лист,
  вся доска), а не по куску, тогда она читается как чистая бумага; резкую тень на доске дели на две фигуры.
  Меряй края `ruler --scale 3` по кадру `clean.ref` / медиане `plate`.
- **Табличка до краёв** — `"fill": "auto"` в зоне (или в `detect`): для табличек/карточек/этикеток в рамке.
  От глифов зоны заливкой по похожему цвету (сосед к соседу, градиент проходит) находится внутренность таблички
  до рамки; текст, его обводка и сглаживание внутри — «дыры», заполняются тоже (текст, касающийся края, и
  табличка, разрезанная высоким иероглифом на половинки, обрабатываются). Модель фона выбирается по остатку на
  пикселях таблички вне текста и его свечения: `const` (один цвет), `rows` (цвет на строку — вертикальный
  градиент), `cols` (цвет на столбец); остаток больше `fill_tol` (5 уровней, по сглаженному 7×7 изображению,
  бандинг крутого градиента не считается) или в табличке есть посторонние элементы (иконка без глифов) —
  зона уходит в обычную маску глифов (лог сборки: `zone [...]: no plate ... (rejected: ...)`). Рисуется не
  мозаикой, а ровными полосами: прямоугольник на серию строк (столбцов) одного цвета и пролёта, одноцветная
  прямоугольная табличка — один прямоугольник; шва внутри нет (заменяется всё до рамки), размер — единицы КБ.
  Табличку ищет по медиане всего плана (`plate`), поэтому она должна стоять на месте весь элемент (статичный
  оверлей или статичный план; при `attached` + `affine` полосы едут по треку). Ключи: `fill_step` (3 — допуск
  шага заливки), `fill_reach` (300 px — где искать вокруг зоны), `fill_glow` (10 px — свечение текста не
  участвует в подгонке), `fill_erase_all` (стирать и посторонние элементы). `"fill": "rows"|"cols"|"const"` —
  сам `box` считается табличкой, модель задана; `"fill": true` — вся зона гладкой заливкой (размытый текст на
  ЖК-экране). `analyze` ставит `fill: auto` сам, если табличка найдена и не меняется от первого до последнего
  кадра (иначе пишет `plate found but it changes ...` — обычно тайминг заходит на следующую надпись).
- `detect` — как найти глифы: медиана кадров `frames` (текст полностью виден).
  `polarity: "light"` (по умолчанию) — глиф ярче локальной медианы (окно `win`) на `thr` и самый тёмный канал > `minc`;
  `absw` — ещё и почти белые пиксели ярче этого (плотные иероглифы).
  `polarity: "dark"` — тёмный текст на светлом: темнее медианы на `thr`, самый яркий канал < `maxc`
  (цветную кайму/аберрацию вокруг букв ловит больший `maxc` и `dil`).
  `dil` — раздувание (свечение), `close` — склейка, `shadow: {off: [dx,dy], dil}` — захватить смещённую тень.
  Пороги не угадывай: `TS probe -c episode.json --frames a:b --box <глифы> [--bg <чистый фон рядом>]` печатает
  перцентили яркости глифов и фона, предлагает `minc`/`absw`/`maxc` и находит строки, где кончаются глифы и
  начинается линия (→ низ `zone`).
- `attached: true` — текст **принадлежит сцене** (экран, доска, вывеска) и едет вместе с камерой: маска
  ищется на кадре `clean.ref`, заплатка — фигура без клипа, которая едет по треку, русский текст тоже едет
  (`\move` + `\t(\fscx\fscy\frz)`: поворот трека тоже передаётся — лист/телефон в руке; сдвиг — нет).
  Позиции текста задаются в кадре `ref`; свой `\frz` текста складывается с поворотом трека.
  Без `attached` текст — неподвижный оверлей (титр) над движущимся фоном: клип стоит на месте.
  **Не ставь трек, если фон неподвижен** (двигается только персонаж): ECC на гладкой доске «уводит» заплатку,
  и к концу плана она заметно темнее/сдвинута — сначала сравни пиксели фона в разных кадрах (`ruler --std`).
- `clean.mode`:
  - `inpaint` — гладкая заливка по краю зоны. Статичный план: фон = медиана `plate: [a,b]`.
    С `motion: affine` — заливается кадр `clean.ref` и ведётся треком; работает и без `attached` — это случай
    «текст с первого кадра плана, чистых кадров нет, план зумится/едет» (с `attached` заплатка едет вместе
    с объектом, без него клип стоит на месте).
    На текстурах (сетка экрана, кирпич, ткань) заливка гладкая и заметна — см. troubleshooting;
  - `ref` — чистый фон из кадра `ref` до появления текста (+ `pre: [a,b]` — ещё кадры для медианы, убирает
    снег/шум), ведётся аффинным трекингом ECC по кадру (`motion.mode: affine`; `rows` — полоса кадра для
    трекинга, `exclude` — неподвижные оверлеи (для не-attached зоны текста исключаются сами), `denoise` —
    медианный фильтр от снега).
- `ring` — где сравнивать цвет чистого фона с текущим кадром (засветка/затемнение по ходу плана):
  `outer` бокс минус zone±`inner_pad`. `segments` — куски с линейной интерполяцией движения, или `"auto"`:
  разрезать там, где линейная интерполяция положения/масштаба/поворота уводит углы заплатки дальше
  `motion.seg_tol` (0.6 px) + `motion.seg_rel` (0.1) × скорость, и на концах проявления текста (рука с листом);
  `color_keys` — доп. кадры-ключи цвета.
- `text` или `texts` (список).

## type: follow — текст, который едет за логотипом

```json
{"id": "logo", "type": "follow", "frames": [6224, 6343],
 "track": {"ref": 6312, "search": [250, 300, 1700, 760], "dark": 90, "fit_frames": [6232, 6340], "min_score": 0.6},
 "text": {"text": "ЧЁРНЫЙ КЛЕВЕР", "style": "Логотип", "cap": 26, "span": [663, 1261], "base": 733, "layer": 30, "tags": "\\blur3"},
 "occluders": {"from": 6313, "thr": 128}}
```
- `track`: тёмный логотип в `search` на кадре `ref` становится шаблоном; на каждом кадре ищется масштаб и центр,
  по кадрам `fit_frames` с уверенностью > `min_score` — линейная подгонка (зум с постоянной скоростью).
- `text` в кадре `ref`: `cap` — высота заглавных (px) → кегль; `span: [x0, x1]` — растянуть по ширине
  межбуквенным интервалом (как «B L A C K  C L O V E R»); `base` — базовая линия.
- `occluders.from` — с этого кадра текст режется `\iclip` по тёмным силуэтам (`thr`) покадрово.
  До этого — одна строка `\move` + `\t(\fscx\fscy)`.

## type: text — только текст

`{"id": "...", "type": "text", "frames": [a, b], "text": {...} | "texts": [...], "area": [x0,y0,x1,y1]}`
`area` — где кадрировать контрольный лист.

Песни (и любая группа строк переводчика по актёру/стилю) — элемент `song-NN` на строку, его делает analyze
(фильтр `--songs`) или `TS add -c episode.json --match <regex> [--preset <набор>] [--prefix <id>]`:
`{"id": "song-01", "type": "text", "frames": [...], "source_lines": [<строка>], "text": {"text": "...",
"preset": "song", "pos": [960, 34], "an": 8, "fade": [180, 180]}}` — с набором пресета; без него
`"text": {"source": true}` (строка переводчика как есть). merge убирает из сабов именно эти `source_lines`.

`track` — текст без маски едет за камерой / объектом (иероглиф на клинке, вывеска на проезде, карта на зуме):
```json
"track": {"mode": "shift", "roi": [600, 0, 1320, 1080], "ref": 171343}
```
- позиции текста (`x`/`base`/`pos`) задаются в кадре `ref` (по умолчанию первый кадр элемента);
- `mode: "shift"` — сдвиг по фазовой корреляции `roi` от кадра к кадру (накопленный): длинные панорамы и
  наклоны, где последний кадр уже не пересекается с `ref`; только сдвиг (`axis: "x"|"y"` — по одной оси);
- `mode: "affine"` — ECC против кадра `ref` внутри `roi` (минус `exclude`): зум и поворот, но `roi` должен
  оставаться в кадре; трек считается на кадрах в `scale` (0.5) от размера анализа;
- строки — `\move` по отрезкам (`seg_tol` 0.6, `seg_rel` 0.1) + `\t(\fscx\fscy\frz)`, как у `attached`;
  `\fade` идёт через весь элемент. Трек кэшируется (`cache/ttrack_*.npy`) — правка текста пересобирается за секунды.
  В логе сборки `text track: roi centre moves ...` — сверь со сдвигом на `grid`.

## Пресет (presets/<тайтл>.json)

```json
{"playres_y": 360,
 "styles": ["Style: ...", ...],          // размеры для PlayResY = playres_y; масштабируются под скрипт
 "match": ["black clover", "блэк кловер"],   // слова в имени видео/надписей -> analyze выберет этот пресет
 "card": {"layers": [...], "title_em": 36, "name_em": 54, "name_base_off": 14, "title_base_off": 9,
          "line_style": "Линия", "line_pad": 46, "line_r": 3.1, "line_th": 0.65,
          "glow_fit": true, "glow_band": true, "halo": 0.015, "seam": true},   // умолчания свечения карточек
 "sign": {"layers": [...]}, "title": {"layers": [...]},   // любые именованные наборы слоёв для text.preset
 "glow": {"sig": [...], "w": [...], "C": [0, 0, 0]}}       // модель тёмного свечения элементов карточки
```
Стиль `Маска` (без обводки, `\an7`) обязателен — им рисуются заплатки. Имена стилей пресета не должны совпадать
с диалоговыми стилями сабов (merge удаляет строки этих стилей при повторной вставке).
